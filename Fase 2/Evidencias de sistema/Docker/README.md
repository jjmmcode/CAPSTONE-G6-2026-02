# Docker: no aplica

Anvil of Ambition es un videojuego de escritorio desarrollado en Godot 4.7. Se ejecuta localmente, sin servidor ni servicios en red, por lo que no requiere contenedores para funcionar ni para desplegarse.

- **Ejecución:** desde el editor de Godot (ver `Fase 2/Evidencias de sistema/Aplicación/README.md`).
- **Distribución:** exportación ejecutable para Windows generada desde Godot (pendiente, requisito RNF-14).
- **Datos:** archivos locales en `user://` (ver `Fase 2/Evidencias de sistema/Base de datos/README.md`).

El `Dockerfile` y el `compose.yaml` de esta carpeta son los ejemplos del repositorio base de la asignatura y se mantienen sin cambios para respetar la estructura exigida.
